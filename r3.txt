# 10. RAZORPAY PAYMENT

Use **Razorpay** for Corporate event registration payments.

Frontend environment:

```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_RAZORPAY_KEY_ID=rzp_test_xxxxxxxxx
```

Only the public Razorpay Key ID can be exposed to frontend.

NEVER expose:

```env
RAZORPAY_KEY_SECRET
RAZORPAY_WEBHOOK_SECRET
```

in frontend.

These remain backend-only.

Payment flow:

```text
Registration
     ↓
Create Razorpay Order
     ↓
Backend
     ↓
Razorpay Checkout
     ↓
Payment
     ↓
Payment Response
     ↓
Backend Verification
     ↓
Registration Confirmation
```

Do NOT mark registration confirmed simply because Razorpay returns success.

The backend must verify the payment.

After verification, fetch the final registration status from the backend.
